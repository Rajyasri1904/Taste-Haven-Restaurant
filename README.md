# Taste-Haven-Restaurant
🍽️ Taste Haven – Restaurant Website

A beautifully designed and responsive restaurant website created using HTML and CSS. Taste Haven provides an elegant online presence for a restaurant, showcasing delicious food, special offers, customer reviews, and contact information in an attractive layout.

🌟 About the Project

Taste Haven is a restaurant website project designed to deliver a visually appealing and user-friendly experience. It features a modern design, attractive food imagery, and organized sections that help visitors explore the restaurant's offerings.

The website is built with beginner-friendly web technologies and focuses on creativity, clean layout, and responsive design.

✨ Features

- 🏠 Hero Section – Attractive landing page with a welcoming introduction.
- 🍕 Food Menu – Displays delicious food items with images and details.
- 🎉 Special Offers – Highlights exciting deals and discounts.
- ⭐ Customer Reviews – Showcases customer feedback and experiences.
- 📍 Contact & Location – Provides restaurant contact and location information.
- 📱 Responsive Design – Designed to look good across different screen sizes.
- 🎨 Modern UI – Clean layout, appealing colors, and stylish typography.

🛠️ Technologies Used

- HTML5 – For webpage structure and content.
- CSS3 – For styling, layout, colors, animations, and responsiveness.
